# Shadewright Labs Homebrew tap

Homebrew formulae for Shadewright Labs tools on macOS (Apple Silicon and Intel) and Linux (Ubuntu / Linuxbrew).

## Install Sablecourt

Once a release tag (such as `v0.1.0`) is published and checksums are updated in `Formula/sablecourt.rb`:

```bash
brew tap shadewright-labs/tap
brew install shadewright-labs/tap/sablecourt
```

Or in a single command:

```bash
brew install shadewright-labs/tap/sablecourt
```

This installs both `sablecourtd` and `sablectl`.
